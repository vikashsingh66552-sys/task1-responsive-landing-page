# TaskFlow - Responsive Landing Page

A modern, responsive landing page built for Task 1 using semantic HTML, CSS, and vanilla JavaScript.

## Features
- Responsive desktop, tablet, and mobile layouts
- Sticky navigation with a mobile hamburger menu
- Hero section with dashboard preview
- Features, workflow, testimonial, pricing, CTA, and footer sections
- Smooth in-page navigation and accessible menu controls
- Reduced-motion support and basic SEO metadata

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

No build tools or dependencies are required. The Google Fonts import requires an internet connection; system fallbacks are provided.

## Deploy with GitHub Pages
1. Create a public GitHub repository, for example `task1-responsive-landing-page`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The live URL will appear in the Pages section.

## Submission
Submit the GitHub repository URL in the Task 1 repository field. The assignment also asks for a LinkedIn post URL containing a short video explanation or demo. Publish that post separately and paste its actual URL in the second field.
